# Anurag Garg Portfolio

Static GitHub Pages landing page for Anurag Garg, a physics educator and
independent researcher working across astrophysics, machine learning, physics
education research, and scientific computing.

## Structure

- `index.html` contains the full landing page markup and styles.
- `assets/physics-portfolio-hero.png` is the generated hero image used by the homepage.
- `_config.yml` keeps the GitHub Pages site title and metadata.

## Current Sections

- About
- Research areas
- Featured projects
- Teaching and resources
- Publications and research profiles
- Open science links
- Contact links
